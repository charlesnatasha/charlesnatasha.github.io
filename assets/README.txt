<!-- PLACEHOLDER FOR YOUR CV -->

This folder should contain your CV/Resume file.

INSTRUCTIONS:
1. Create or download a PDF version of your CV/Resume
2. Name it "portfolio.pdf"
3. Place it in this folder (assets/)

Once you've added your portfolio.pdf file:
- The "Download CV" button in the hero section will work
- Visitors can download your CV when they click the button

FILE LOCATION:
Your Portfolio/
└── assets/
    └── portfolio.pdf  ← Add your CV here

SUPPORTED FORMATS:
- .pdf (recommended)
- You can also use .doc or other formats by renaming the file and updating the link in index.html

For more details, see the README.md file in the root folder.
